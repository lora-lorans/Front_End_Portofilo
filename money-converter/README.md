## ✨ About the Project

**Currency Converter** is a web project designed to provide a simple interface for converting between the **US Dollar (USD)** and the **Syrian Pound (SYP)**.

The project features a modern design with a green and beige color palette, responsive layouts, and a dedicated contact page.

### 🎯 Project Goals

- 💱 Create a simple currency conversion interface.
- 📱 Provide a responsive experience across different screen sizes.
- 🎨 Build a clean and attractive user interface.
- 🔄 Support the concept of two-way currency conversion.
- 📬 Provide an About Us page and a Contact Us page.

## 🚀 Features

- 💵 **USD & SYP Interface** — Input fields for both currencies.
- 🔄 **Two-Way Conversion Design** — A visual indicator showing the conversion direction.
- 📱 **Responsive Layout** — Designed to adapt to desktop and mobile screens.
- ✨ **Modern UI** — Glassmorphism effects, soft shadows, and rounded corners.
- 🎞️ **Animated Backgrounds** — Smooth CSS animations on selected pages.
- 🏷️ **Currency Icons** — Flags and currency-related symbols.
- 📬 **Contact Page** — A dedicated interface for questions and feedback.
- 👤 **About Us Page** — Introduces Lotus Designs.

## 💡 How to Use

1. 🌐 Open the Currency Converter website.
2. 💵 Enter an amount in the USD field.
3. 🔄 Use the conversion interface to select or enter the other currency amount.
4. 🇸🇾 View the corresponding SYP value.
5. 📬 Visit the Contact Us page to explore the contact form.

> ⚠️ **Exchange Rate Notice:** The displayed rate of `1 USD = 13,000 SYP` is an example value used in the interface. Exchange rates change over time. Update the rate using a reliable source before relying on conversion results.
